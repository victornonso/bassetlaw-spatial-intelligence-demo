## Presentation introduction

I built a small public-data prototype to show how a map can become a reusable, traceable answer to a council question.

## Five likely questions

**Does this replace a planner?** No. It organises evidence and exposes limitations. Professional judgement, policy and site-specific assessment remain essential.

**Why use historical wards and register points?** They are openly available documented snapshots. I would choose the appropriate current authoritative geography for operational use and retain the version used in every analysis. A point cannot establish a site's extent.

**What happens when the API sleeps?** The interface can use packaged public snapshots, labelled as browser analysis with its own distance method. For interview-day reliability I would verify latency and consider an approved always-on backend tier.

**How would this connect to real council records?** Through agreed ownership, common identifiers such as the Unique Property Reference Number and controlled services, with access and licensing checks. The prototype does not assume Bassetlaw's systems are already linked or unlinked.

**What is the greatest limitation?** Data scope and vintage. The loaded schools are one bounded service example; straight-line distance is not a journey, capacity or demand model. I would agree the question with service leads before adding more data or analysis.
