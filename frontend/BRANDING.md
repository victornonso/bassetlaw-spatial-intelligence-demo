# Visual system provenance

Inspected live official Bassetlaw District Council homepage and its own stylesheet on 17 November 2026.

- Homepage: https://www.bassetlaw.gov.uk/
- Stylesheet: https://www.bassetlaw.gov.uk/css/Bassetlaw-District-Council-Min.css
- `#4D7A7A`, RGB 77, 122, 122: `.btn-teal`, `.backteal2`, `.atoz a`, `.cardteal`; selected primary here.
- `#3E6362`, RGB 62, 99, 98: `.btn-teal` border; selected dark accent and text links here.
- `#009494`, RGB 0, 148, 148: `.backteal` and `.btn-teal:hover`; reserved secondary accent here.

These are observed public CSS values, not a claim to a formal corporate brand manual. The Council logo supplied by Victor Okeke on 18 November 2026 is displayed unchanged in the application header. The application remains explicitly labelled as an independent interview prototype. The logo asset is not covered by the open-data licences of the mapped datasets. Font: Arial/Helvetica system sans-serif. Light neutral backgrounds, conventional buttons, thin rules and a map-dominant 71/29 workspace distinguish this as a working civic GIS prototype. Map flood and greenspace symbology use semantic blue/green rather than forcing brand colour onto data.
